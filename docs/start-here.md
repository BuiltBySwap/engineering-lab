# Start here: how to follow this book

This site is a learning book written while learning. Anyone can follow it in order, and every page has the same shape.

## The book in four parts

| Part | Where | What you get |
|---|---|---|
| **Sessions** | [Progress](progress.md), [Tags](tags.md) | One notebook per session (`AI-02`, `BE-01`...): notes, examples, runnable code, bug diary |
| **Mobile Exploration** | [Mobile Exploration](mobile-exploration/index.md) | One "how does it really work?" question a day, with a guess, the verified answer, and a status |
| **English** | [Word of the day](english/index.md) | Two words a day, a weekly grammar point, my sentences and the corrections |
| **Role lens** | [Role lens](role-lens/index.md) | The same topic seen as Mobile Dev, Mobile Lead, Team Lead and CTO, plus a thinking model each week |

Every day has one page: [Status](status.md) shows today and what is still open.

## The daily loop (about 1 hour)

1. **Guess** the day's Mobile Exploration question in 2 lines.
2. **Learn** the session topic in its notebook (predict before you run).
3. **Run** the examples. Python runs in Colab; Kotlin runs with `%%kotlin`.
4. **Write** the answer, the bug diary and the takeaway in your own words.
5. **English and role lens:** 3 sentences with the day's words, and one question from one seat.
6. **Update** the day file and the notebook's status card, then push.

- Use the search box on the [home page](index.md) to find anything, including code.
- The code lives in separate repos: see [Code repositories](repos.md).
