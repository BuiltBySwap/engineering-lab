# Origin-story note template

Copy this for every topic.

```
## [ID] · [Date] · [Topic]
1. Problem: what hurt before this existed?
2. Old way: what did people do before?
3. Why it broke: at scale / in production
4. The invention: who / when / what idea
5. How it works inside: (draw or describe)
6. Where I've used it:
7. Trade-offs: when would I NOT use it?
My mistakes today:
In my own words:
```
